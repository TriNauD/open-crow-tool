# 划词保存重复笔记校验 — 保姆级手动测试

## 环境

| 项 | 说明 |
|----|------|
| Web | future 分支 `npm run dev` |
| 扩展 | `chrome-extension` build 后加载 dist；Options 连同一 API 并**已连接账号** |
| 账号 | 同一登录用户 |

## A. 命中重复 → 都保留

1. Web 首页问并保存词条 `RAG 是啥`（或任意固定短句）。
2. 任意网页划选 **`rag是啥`**（大小写/空格不同）→ 解释 →「存入笔记本」。  
   **预期**：卡片内提示「已有同名笔记」，按钮「都保留 / 覆盖旧的」。
3. 点「都保留」。  
   **预期**：提示已保存；笔记本列表出现**两条**同题（新旧解释可不同）。

## B. 覆盖旧的

1. 再划同一 normalize 文本 → 存入 → 选「覆盖旧的」。  
   **预期**：列表中该 normalize 下顶层笔记数量合理减少（旧一条被删、新一条在）；打开笔记本核对。

## C. 未登录

1. 断开插件连接后划词解释。  
   **预期**：仍可解释；保存区为「连接插件…」，**不**误 POST。

## 失败看哪里

- Network：`GET /api/notes?q=`、可选 `DELETE /api/notes/:id`、`POST /api/notes`；401 → session refresh。
- 未弹确认却直接存 → 扩展未 rebuild / normalize 不一致。
