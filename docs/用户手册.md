## 0. 三十秒了解

**「这是啥？」**（Crow Knows）是一个 AI 技术黑话翻译工具：把让你头大的 AI 术语、新工具、震惊体新闻丢进去，它用大白话告诉你这玩意儿是干嘛的。看懂了可以一键存进笔记本，划出答案里任何不懂的词还能继续追问。另外每周一发一封 GitHub 热榜点评邮件（订阅免费）。

| 功能 | 名字 | 入口 |
|------|------|------|
| 问 AI | **这是啥** | 网站 / Chrome 扩展划词 |
| 追问 | **这又是啥** | 在答案里选中任意词 |
| 记笔记 | **这都是啥** | 笔记本页面 |
| 周报 | **鸦速通热榜** | `/subscribe` 订阅 |

**站点地址**：生产 [https://www.crowknows.tech](https://www.crowknows.tech)（团队开发/预览环境为 `dev.crowknows.tech` 与 `*.vercel.app`，仅供内部联调用）。

## 1. Web 端（网站）

### 1.1 问第一个问题

1. 打开网站首页，在输入框粘贴/输入任意内容：术语（`MCP 是啥`）、一段看不懂的技术新闻、或一整段文章。
2. 按 **Enter** 发送；想写多行内容用 **Alt+Enter**（或 Shift+Enter）换行。`⌘/Ctrl+Enter` 也可以发送。
3. 答案**流式**逐字输出，一般几秒内开始出现。
4. 支持粘贴纯链接：检测到 URL 时会提示按链接读取方式解释。

### 1.2 读解释：复制 / 存笔记 / 重试

解释完成后，卡片底部有一排操作：

- **复制**：把完整解释以纯文本复制到剪贴板，按钮短暂变为「已复制」。
- **存到笔记本**：登录用户存云端，未登录存游客态（见 1.4）。重复保存同一问题时会弹对比框，可选「两个都存」或「替换旧答案」。
- **重试**（失败时出现）：请求失败时红字报错旁有「重试」，点击会**原样重发**同一条请求。

### 1.3 追问：这又是啥？

在**任意解释卡片的文字**（包括你的问题和 AI 的回答）里用鼠标选中一个词，词上方会浮出橙色按钮 **「这又是啥？」**，点击即在当前卡片下方嵌套一张新卡片继续解释，原答案会作为上下文传给 AI。可以一层层嵌套追问下去。

### 1.4 笔记本（这都是啥）

- 入口：首页右上角 → 笔记本；或直接访问 `/notebook`。
- **登录用户**：笔记存在云端，换设备登录后都在。
- **游客态**：笔记存在本机浏览器的 localStorage，不注册也能用；**清除浏览器数据/换设备会丢**，登录后系统会引导把游客笔记一键迁移到云端。
- 列表默认折叠，点击展开全文；带「追问」「插件」小标签区分来源。
- **搜索**：输入关键词即时过滤（本地过滤，输入秒出结果）；关键词按「输入 + 解释」两个字段匹配，不区分大小写。逗号、`%` 等特殊字符都能正常搜。
- 每条笔记可删除。

### 1.5 注册 / 登录

- `/register` 注册（需密码确认）、`/login` 登录。注册后按邮件提示确认邮箱（如配置了确认流程）。
- 会话过期后重新登录即可；登录状态决定笔记存云端还是游客态。

## 2. Chrome 扩展（划词解释）

### 2.1 安装

团队发布渠道安装；或本地构建加载：

```bash
cd chrome-extension
npm install
npm run build        # 产物在 dist/
```

Chrome → 扩展程序 → 开启「开发者模式」→「加载已解压的扩展程序」→ 选 `chrome-extension/dist/`。

### 2.2 连接账号（三种方式）

| 方式 | 操作 | 适用 |
|------|------|------|
| 扩展内登录（推荐） | 点扩展图标 → Popup → 按提示登录 | 所有人 |
| 网站「连接插件」 | 登录网站后点页面上的连接入口 | 快捷同步 |
| 手动 Token | Options → 高级 → 填 API 地址 + 访问令牌 | 调试兜底 |

连接成功后，扩展内保存的 API 地址与 token 与该环境一致。**换环境**（比如从开发站换到生产站）需要在对应环境的网站上重新「连接插件」。

### 2.3 划词解释

1. 在任意网页选中一段文字，旁边浮出**乌鸦浮标**；点击（或按快捷键）即弹出解释卡片。
2. 未连接账号也能划词解释（走公开接口）；要把解释**存进笔记本**时才需要连接，卡片上会有引导。
3. 解释失败（比如网络问题）可在卡片里**重试**。

### 2.4 开关与快捷键

- **暂停划词**：Popup / Options 里有开关，关闭后不再触发划词 UI，快捷键也不进入解释。开关会同步到已打开的标签页。
- **快捷键**：Windows/Linux `Alt+W`；Mac `Ctrl+Shift+W`（可在 `chrome://extensions/shortcuts` 自定义）。
- 扩展更新/重载后，旧标签页里的浮窗会自动清理，不会留「僵尸 UI」；个别残留按 Esc 或刷新页面即可。

### 2.5 扩展 FAQ

- **划词报「网炸了或者 AI 挂了」**：多为网络问题或所连环境不可达；先看是否连接了正确环境的 API 地址。Preview 域名开着 Vercel 部署保护时，扩展请求会被拦（401），联调请用生产域或本地。
- **浮标不出来**：检查暂停开关是否被关掉；刚安装/更新后刷新一下页面。
- **存笔记提示需要连接**：正常流程，点卡片引导完成连接后再存。

## 3. GitHub 周报（鸦速通热榜）

### 3.1 订阅

1. 打开 [/subscribe](https://www.crowknows.tech/subscribe)，输入邮箱提交。
2. 收到「订阅成功」欢迎邮件，说明已进列表。
3. 重复订阅同一邮箱不会重复收信；**取消过再订**会直接复活订阅（会收到「欢迎回来」邮件）。

### 3.2 邮件内容

每周一 17:00（北京时间）发送：本周 GitHub Trending Top 20，按 AI 五档评审排序——

`🔥 夯 · ⚡ 顶级 · ✨ 人上人 · 😐 NPC · 💩 拉完了`

每条含一句话大白话点评 + 技术/场景双维度打分 + 项目链接。

### 3.3 退订（两步确认）

1. 点邮件底部「退订」链接，会打开**确认页**（只展示，此时还没退订）。
2. 点页面上的 **「确认退订」** 按钮才真正生效，随后收到退订确认邮件。

> 为什么两步？部分邮件客户端（Apple Mail 隐私代理、Outlook SafeLinks 等）会**自动预取**邮件里的链接，老版本「点都不点就被退订」。现在只有你在确认页亲手点按钮才会退订。

误退订了？用同一邮箱重新订阅即可复活；或用确认邮件里的「重新订阅」链接。

## 4. 报错速查表

| 提示 | 含义 | 怎么办 |
|------|------|--------|
| `请求太频繁了，请稍后再试`（429） | 触发按 IP 限流（默认 60 次/小时） | 稍后再试；自部署可在环境变量 `RATE_LIMIT_EXPLAIN_PER_HOUR` 调整 |
| `文本太长了（上限 12000 字符）`（413） | 输入超长 | 截取重点段落再试 |
| `Origin 不被允许`（403） | 从第三方网页直接调接口 | 网站内使用、或用官方 Chrome 扩展 |
| `网炸了或者 AI 挂了` | 网络/上游 AI 异常 | 点「重试」；AI 主通道挂起时系统会在约 18 秒内自动切换备用通道 |
| 扩展请求 401 | 所连环境开了部署保护 / token 失效 | 到对应环境网站重新「连接插件」 |
| `链接无效`（退订页） | 退订链接已用过或失效 | 已退订则无需操作；否则重新订阅 |

## 5. 数据与隐私

- **游客笔记**：只存本机浏览器 localStorage，不上传；清除浏览器数据会丢失。
- **云端笔记**：登录后存 Supabase，按用户隔离（RLS），只有本人能读写。
- **订阅邮箱**：仅用于发送周报与订阅状态通知；退订后不再发送，记录保留以便「重新订阅复活」。
- **划词解释**：选中文本会发送给 AI 服务用于生成解释；未连接账号时走公开接口（有频率限制）。

## 6. 已知限制

- 解释输出目前是短句风（3～5 句），对整页长文可能偏简短；输出分档在路线图上（R9）。
- 周报发送为顺序发送，订阅人数很大时全量发完需要时间（分批发送在路线图上，R14）。
- 笔记搜索为本地过滤，笔记数千条后如需更强全文检索会再升级（R17）。
- 移动端触屏上 Enter 是换行、发送靠按钮（无 Alt 键），角标文案在移动端不展示。
